## Practical model

Each sphere falls at its Stokes terminal velocity v = (2/9)(ρs − ρL) g r² / η, with ρs = 7.86, ρL = 1.26 g/cm³,
g = 980 cm/s² and η = 12.0 P for the glycerin (about 22 °C). The sphere settles to that velocity with a 0.03 s time
constant and slows within 3 cm of the base. Balls 1–3 have r = 0.20, 0.25 and 0.30 cm; with D = 30.0 cm the timed
values come out about 6.26, 4.01 and 2.78 s, matching the worked example (S = 120.0 cm⁻¹ s⁻¹, η = 11.98 P).
